# CampusConnect — Responsive Landing Page

A responsive campus-services landing page built with **HTML, raw CSS, and vanilla JavaScript**. It follows the provided Base MVP and UI/UX requirements without using Bootstrap or Tailwind.

## Included
- Responsive navbar with mobile hamburger menu
- Hero section with headline and Get Started CTA
- Three service cards (Events & Activities, Resources, Community)
- Footer with quick links and social links
- Dark/light theme toggle using a CSS class on `<body>`
- Hover effects and sticky/frosted navigation
- Responsive mobile, tablet, and desktop layouts
- Reduced-motion support and basic accessibility labels

## Run it
1. Extract the ZIP file.
2. Open `index.html` in a browser.
3. For a development server, open the folder in VS Code and use the Live Server extension if available.

## Files
- `index.html` — page structure
- `style.css` — layout, raw CSS Grid/Flexbox, responsive styles, and themes
- `script.js` — theme toggle, mobile menu, active links, and copyright year

## Important requirement note
The brief says Phase 1 must use raw CSS and prohibits UI frameworks.
